Herdr’s TUI is great.
Here’s what a window adds.

Herdr UI is a native client for the Herdr daemon you already run. Your terminals and agents stay in the daemon; the window adds dispatch from issues, side-by-side review, checkpoints, Teleport and a Devices overview.

Keep the TUI. Add Herdr UI.
Install the app next to the Herdr you already have. It attaches to your daemon and never installs or upgrades it, so install Herdr first.

      

          
        

        
macOS

          
$brew install penso/tap/herdr-gpui

          
macOS 14.2+, signed, notarized, universal · or the .dmg

        
Linux

          
$curl -fsSL https://herdrui.dev/install.sh | sh

          
x86_64 and ARM64 · installs the checksummed .deb, .rpm or Arch package with APT, DNF or pacman (glibc 2.39+) · read the script · or nix run github:penso/herdr-gpui

        
Windows

          
PS>irm https://herdrui.dev/install.ps1 | iex

          
x86_64 and ARM64 · installs for the current user, adds a Start menu entry · read the script · WSL daemons work too

        
All install options · llms.txt

        
Then run herdr in a terminal and open Herdr UI: both show the same panes.
